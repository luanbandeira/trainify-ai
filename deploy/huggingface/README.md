# Trainify AI

Microserviço de RAG do Trainify: chat por perfil e geração de quiz a partir do
material dos cursos. Esta página abre a interface de demonstração, com a base de
conhecimento das Normas Regulamentadoras (NRs) de segurança do trabalho.

Código-fonte, pipeline e instruções de execução: veja o repositório do projeto.
